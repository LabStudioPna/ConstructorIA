Términos y Privacidad

Última actualización: Julio 2026

1. Uso de BarIA

BarIA es una herramienta de apoyo para costeo de bebidas y consultas normativas en bares y restaurantes. No reemplaza a un POS, a un contador ni a asesoría legal formal.

Al usar BarIA aceptás que sos responsable de verificar la información normativa con las autoridades competentes de tu jurisdicción. Los horarios, requisitos y regulaciones cambian — BarIA intenta estar actualizado, pero siempre confirmá con organismos oficiales.

2. Tu API Key de Anthropic

Para usar BarIA necesitás una API key de Anthropic (gratis desde console.anthropic.com).

Tu API key nunca llega a nuestros servidores. Se almacena únicamente en sessionStorage de tu navegador. Al cerrar la pestaña se borra automáticamente.

Vos sos responsable de:

  • Mantener tu API key confidencial
  • No compartirla con terceros
  • Monitorear tu consumo de crédito en Anthropic (pagás directamente a Anthropic, no a nosotros)
  • Limpiar tu navegador si accedés desde una máquina compartida

3. Privacidad de tus datos

Qué guardamos

Si contratás el Plan Bar, podés conectar tu Google Sheets personal. Tus datos se guardan en tu propia hoja (en tu Google Drive), no en servidores nuestros.

No guardamos:

  • Tus recetas
  • Tus consultas al chat
  • Tu API key
  • Información de tu bar

Qué pasa con Anthropic

Tu API key va directa a Anthropic. Revisá su política de privacidad para entender cómo procesan datos. Anthropic puede usar tus inputs para entrenar/mejorar modelos (según sus términos), pero no guardamos copia local.

4. Cookies y rastreo

BarIA no usa cookies de rastreo. Solo usamos sessionStorage y localStorage para guardar tu API key y preferencias locales — nada se envía a terceros.

5. Plan Estudio / Plan Bar

Si contratás el plan pago (USD 80/mes):

  • Facturamos directamente a tu email
  • Tus datos de contacto se guardan en nuestro CRM (para soporte y avisos de cambios normativos)
  • Podés cancelar en cualquier momento

6. Limitaciones y exención de responsabilidad

BarIA se proporciona "tal cual" sin garantías. No somos responsables por:

  • Errores en el costeo (siempre verificá precios de proveedores)
  • Cambios en normativa que no reflejemos a tiempo
  • Multas o sanciones por incumplimiento normativo
  • Caídas de internet o errores en tu API key
  • Decisiones de negocio basadas en los análisis

7. Cambios en estos términos

Podemos actualizar estos términos en cualquier momento. Si hacemos cambios significativos, te avisaremos por email (si estás en el plan pago).
