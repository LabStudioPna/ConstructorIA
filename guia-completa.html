¿Qué es ConstructorIA?

Una plataforma de IA pensada para constructores que quieren presupuestar, analizar y predecir costos sin pasar horas en Excel.

Cinco módulos específicos, un problema cada uno: Chat de obra, Análisis de planos, Renders 3D, Predicciones ML, Comparador de proveedores.

Sin instalación. Ingresás con Google, cargás tu API key de Anthropic, y empezás a usar en 2 minutos.

Tus datos siempre bajo control. La IA corre en tu navegador. Tu API key y los archivos nunca tocan servidores nuestros.

5 Módulos

1. Chat de obra 💬

Preguntas libres sobre presupuestos, materiales, normativa de construcción, IVA, retenciones. El agente tiene entrenamiento en legislación argentina y bases de datos de precios actualizadas.

Ejemplo: "¿Cuál es la alícuota de ingresos brutos para constructores en Córdoba?" → Respuesta automática con datos vigentes.

2. Análisis de planos 📐

Subís un PDF, JPG o PNG de un plano. ConstructorIA extrae: área total, cantidad de ambientes, materiales inferidos, dimensiones clave.

Luego te genera automáticamente un presupuesto estimado, timeline y lista de materiales.

Precisión: ±5% en área, ±3 días en timeline (mejora conforme agregues proyectos).

3. Renders 3D 🎨

Describís el proyecto (o usás el análisis de plano anterior). ConstructorIA genera visualizaciones 3D en tres estilos: fotorrealista, arquitectónico, minimalista.

Descargables en PNG 4K. Ideales para mostrarle al cliente antes de empezar.

4. Predicciones 📈

Carga histórica de tus proyectos. El sistema aprende y predice: costo final ±5%, timeline ±3 días, alertas de riesgo.

Entrena con machine learning. Después de 10-15 proyectos cargados, la precisión es significativamente mejor.

5. Comparador de proveedores 🏭

Escribís un material (Cemento Portland, Tuberías PVC, Acero). ConstructorIA consulta 5+ proveedores principales en tiempo real y te muestra: precio, entrega estimada, score de confiabilidad.

Busca automáticamente el mejor relación precio/calidad/plazo.

Especificaciones Técnicas

Frontend

  • Agente único: agente-constructor.html (app completa con 5 módulos)
  • Responsive: Desktop, tablet, mobile
  • Dark mode: Auto-guardado en localStorage
  • Auth: Google login (sin crear usuario)
  • API key: Guardada en sessionStorage (se borra al cerrar)

Backend

Node.js + Express. Endpoints principales:

POST /api/auth/register      // Nuevo usuario (Google OAuth)
POST /api/auth/login         // Login

POST /api/projects           // Crear proyecto
GET  /api/projects           // Listar proyectos
POST /api/projects/:id/items // Agregar item presupuesto

POST /api/projects/:id/analyze-plan    // Claude Vision → análisis de plano
POST /api/projects/:id/render           // Midjourney → render 3D
POST /api/projects/:id/predict          // ML → predicción de costo
POST /api/suppliers/compare             // Real-time supplier comparison

Database

PostgreSQL con 10 tablas core:

  • users
  • projects
  • budget_items
  • floor_plans (análisis)
  • renders_3d
  • predictions (histórico ML)
  • suppliers
  • materials_library
  • project_history
  • workflow_logs

APIs Externas

  • Claude (Anthropic): Chat, vision (análisis de planos), generación de recomendaciones
  • Midjourney: Renders 3D de proyectos
  • Supplier APIs: Ferretería Central, Acero y Estructuras, Azulejos Premium, etc. (5+ partners)
  • Google OAuth: Login sin contraseñas

Workflows n8n (Automatización)

1. Welcome Email

Trigger: Usuario nuevo registrado. Acción: Envía welcome email con onboarding y primer 7-day trial.

2. Daily Progress Report

Trigger: 9 AM diario. Acción: Recopila proyectos activos del usuario, calcula varianza presupuestaria, envía resumen por email.

3. Budget Deviation Alert

Trigger: Desviación >5% en presupuesto. Acción: Notifica al usuario por email + Slack + SMS.

4. Auto-Reorder Supplies

Trigger: Stock bajo. Acción: Compara precios entre 5 proveedores, sugiere reorden, crea PO automática.

5. Weekly Digest

Trigger: Cada lunes 8 AM. Acción: Resumen semanal (projects cerrados, presupuestos analizados, predicciones, alertas).

Todos los workflows usan n8n SDK + PostgreSQL + Anthropic API. Se ejecutan con reintentos automáticos y logging.

Integraciones

Claude Vision (analyze-plan.js)

Sube un PDF o imagen de plano. ConstructorIA analiza con Claude Vision y extrae:

  • Dimensiones y área total (m²)
  • Cantidad de ambientes y tipos
  • Materiales inferidos
  • Estimación de costo por m² (según tipo de obra)
  • Timeline estimado

Midjourney Renders (renderers.js)

Describe el proyecto. ConstructorIA genera 3D renders en estilos: fotorrealista, arquitectónico, minimalista.

Photo Analysis (vision-photo.js)

Sube fotos de obra (progress tracking). ConstructorIA analiza: porcentaje de progreso, alertas de seguridad, calidad de trabajo.

ML Predictor (ml-predictor.js)

Historial de tus proyectos → aprende patrones → predice costo ±5%, timeline ±3 días para nuevos proyectos.

Suppliers Integration (suppliers-integration.js)

Conecta con 5+ proveedores: Ferretería Central, Acero y Estructuras, Azulejos Premium, etc. Precios en tiempo real, mejores opciones automáticas.

Preguntas Frecuentes

¿Qué es una API key y cuánto cuesta?

Es una clave personal para usar la IA de Anthropic. Creás cuenta gratis en console.anthropic.com, cargás crédito y generás tu key. Costo típico: USD 5 = 500-1000 análisis (USD 0.01-0.02 por análisis).

¿Mis planos y datos son privados?

Sí. ConstructorIA no tiene backend propio. Tu API key y los archivos van directo de tu navegador a Anthropic. Al cerrar la pestaña, todo se borra del dispositivo salvo lo que vos decidís guardar.

¿Reemplaza al arquitecto o ingeniero?

No. Es una herramienta de apoyo. Acelera presupuestos, análisis y búsqueda de información. La firma y responsabilidad profesional siempre es de quién diseña la obra.

¿Qué precisión tiene en presupuestos?

Primera estimación: ±15% (es una aproximación rápida). Después de cargar 10-15 de tus proyectos propios, la ML mejora significativamente y llega a ±5-8%.

¿Funciona offline?

No. Necesita conexión a internet (para conectar con Anthropic API, Midjourney, y bases de datos de proveedores).

¿Puedo exportar mis proyectos?

Sí. Todos los análisis y presupuestos se descargan en Excel, PDF o JSON.
